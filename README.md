## Descripción técnica
Portafolio de **una sola página** (`index.html`) construido con HTML, CSS y JavaScript, sin frameworks. Presenta las entregas como tarjetas y enlaza a cada sitio y repositorio.

Diseño de estética **Y2K / Frutiger Aero**: paleta blanco y celeste (baby blue), tarjetas de vidrio con reflejos, botones tipo gel "aqua", burbujas flotantes y detalles brillantes. Tipografías **Fredoka** y **Nunito** (Google Fonts). Es responsivo (móvil y escritorio), con foco de teclado visible y animaciones que respetan `prefers-reduced-motion`.

## Guía de uso (ver el portafolio localmente)
1. Clonar el repositorio: `git clone https://github.com/antoaracena/antoaracena.github.io.git`
2. Abrir `index.html` en el navegador, o usar la extensión **Live Server** en VS Code para verlo con recarga automática.
